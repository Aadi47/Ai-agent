# 🤖 AI Agent — Multi-Tool Assistant

An autonomous AI agent built with Python that can perform 
multiple tasks using specialized tools.

## 🛠️ Tools the Agent Uses
- 🧮 **Calculator** — Solves math expressions
- 📅 **Date & Time** — Gets current date and time
- 🔍 **Company Search** — Searches company knowledge base

## 🚀 How to Run

1. Clone the repo
   git clone https://github.com/Aadi47/Ai-agent.git

2. Install dependencies
   pip install -r requirements.txt

3. Add your API key to .env file
   OPENROUTER_API_KEY=your-key-here

4. Run the agent
   python ai_agent.py

## 🧰 Tech Stack
- Python
- OpenRouter API
- OpenAI SDK
